# Exact versions, so a green build stays green.

# `pyproject.toml` declares floors (`fastapi>=0.111`) because those state what
# the code actually needs. Floors alone mean every install resolves whatever was
# released that morning, and on 2026-09-10 that turned three green suites into
# three red CI jobs with no change to our source: Starlette 1.6 stopped
# flattening included routers, and a test reading `app.routes` found nothing
# (D-087).
#
# This file pins the resolution. It is used with `-c` so the floors keep
# documenting intent while the numbers here decide what installs:
#
#     pip install -c constraints.txt -e ".[dev]"
#
# **Refreshing is a deliberate act, not a side effect.** To take newer versions:
#
#     python scripts/refresh_constraints.py       # resolves and rewrites
#     pytest                                      # then prove it still works
#
# Doing it that way means a dependency break is discovered by whoever chose to
# upgrade, in a diff that says so, rather than by whoever pushed next.
#

# by scripts/refresh_constraints.py — do not hand-edit.
